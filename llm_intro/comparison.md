* **개념:** 해커가 AI에게 직접 악의적인 명령을 내리는 것이 아니라, AI가 읽게 될 **외부 데이터(웹페이지, 이메일, PDF 문서 등)에 교묘하게 악성 명령을 숨겨두는 공격**입니다. AI가 이 데이터를 분석하는 순간, 숨겨진 명령을 시스템의 정상적인 지시로 착각하여 실행하게 됩니다.
* **가장 심각한 이유 (AI 에이전트 시대의 보안 파괴자):**

  2. **현실 시스템 침해로의 전이:** 최근 AI는 단순히 글을 쓰는 수준을 넘어 웹 검색, 이메일 전송, 데이터베이스 조회, 결제 등 실제 행동을 수행하는 **'AI 에이전트(Agent)'** 형태로 진화하고 있습니다. 만약 간접 프롬프트 인젝션에 당하면, AI가 사용자의 사적인 이메일을 탈취해 공격자의 서버로 보내거나 내부 시스템의 주요 데이터를 삭제하는 등 **실제 시스템 권한을 장악당하는 심각한 보안 사고**로 직결됩니다.
